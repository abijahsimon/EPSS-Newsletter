1. `NEWSLETTER-PRODUCTION-GUIDE.md` - current responsibilities, next steps, Ben-owned items, placeholder audit, and media review order.
2. `claude-handoff.md` - instructions and priorities for Claude.
3. `source-status.csv` - source-of-truth table for story/material availability.
4. `media-manifest.csv` - available media pools and what still needs selection, extraction, or confirmation.
5. `drive-file-index.csv` - exact Drive file IDs for the main source folder, commencement picks, Schubert files, and Peltzer ZIP.
6. `media-selection/` - the compact human review queue, including the field-photo shortlist.
7. `claude-export/` - Claude's downloaded static export, preserved as a reference bundle with private uploads excluded.
8. `open-questions.md` - questions worth sending to Emmanuel/Nanette/Emily/Jon.
9. `claude-output-crosswalk.md` - line-by-line correction of the previous Claude checklist.
10. `Claude outputs/epss-newsletter-source/` - Claude's complete Vite source packet, preserved intact.
11. `Claude outputs/epss-newsletter-addendum/` - the intact September 9 Peltzer/BALBOA overlay with 22 images and both Vite/DC page variants.
12. `Claude outputs/ADDENDUM-2026-09-14/` - Claude's intact complete 18-page source/addendum package, including the archive pages, five new story pages, runtime files, manifests, and assets.
