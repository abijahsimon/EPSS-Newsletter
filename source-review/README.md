Start here:

1. `claude-handoff.md` - instructions and priorities for Claude.
2. `source-status.csv` - source-of-truth table for story/material availability.
3. `media-manifest.csv` - available media pools and what still needs selection, extraction, or confirmation.
4. `drive-file-index.csv` - exact Drive file IDs for the main source folder, commencement picks, Schubert files, and Peltzer ZIP.
5. `claude-export/` - Claude's downloaded static export, preserved as a reference bundle with private uploads excluded.
6. `open-questions.md` - questions worth sending to Emmanuel/Nanette/Emily/Jon.
7. `claude-output-crosswalk.md` - line-by-line correction of the previous Claude checklist.

Then read the article packets in `story-packets/` when working on a specific section.
