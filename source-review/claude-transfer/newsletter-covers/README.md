# Newsletter Covers For Claude

These JPGs are first-page renders from the public EPSS Department Newsletters archive:

https://epss.ucla.edu/department-newsletters/

Use `newsletter-covers-manifest.csv` for each title, local cover filename, and source PDF URL.

Notes:

- These are for Claude's past-issues/archive design module.
- The local JPGs are easier for Claude to preview than linking every PDF.
- The PDFs themselves were downloaded only into ignored local working storage and are not included here.
- The 2019 archive page link returned a 404 at its legacy path, so its cover was rendered from the working official WordPress upload URL listed in the manifest.
